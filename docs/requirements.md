# SCAMSHIELD AI 요구사항 정의

제출물의 종류는 SSAFY 3회차 요구사항 PDF 28~30쪽, 기능·검증 기준은 2.6절과 3~4장을 적용합니다. 과제 PDF는 프로젝트 폴더 밖에서 제공받은 원본입니다.

## 도메인과 범위

목표는 디지털 사기 의심 시 사용자가 위험 정황을 파악하고 확인·보류 행동을 선택하도록 돕는 것입니다. 입력은 공개 URL과 문자·메신저 텍스트입니다. URL 조회, 글 속 정황, 조건 미충족 및 조회 실패를 구분합니다. 사용자가 명시적으로 요청한 예방 계획과 세션별 실행 로그를 저장합니다.

| 요구사항 | SCAMSHIELD 적용 |
|---|---|
| F3001~F3004 | LangChain Tool 등록, urlscan.io 공개 후보 검색, VirusTotal 상세, Google Safe Browsing 목록 근거 |
| F3005~F3011 | 사용자 입력·기간·범위 추출, 계획, 조회·통합, 조건 비교, 재계획, 세션 기억과 예방 행동 |
| F3012~F3014 | 이벤트 발행, SQLite 로그 저장, 세션별 조회·삭제 및 수정 차단 |
| F3015~F3016 | 명시적 계획 저장, 목록·상세, 일정 중복 안내, 수정·삭제 |
| F3017~F3019 | FastAPI, 한국어 화면, 실제 이벤트 기반 실행 타임라인 |
| NF3001~NF3007 | 키·오류 노출 제한, 일부 실패 대응, 상한, 단건 지연 검증, 구조 분리, 출처·이용 조건 기록 |
| F3020·F3021 | 규칙 이상 징후와 별도 진단, Planner·Worker·로깅 Agent 역할 분리 |
| F3022·F3023 | 이번 제출 범위에서 보류 |

## 대표 요청과 제약

- 공개 URL을 검사해 달라는 요청은 출처별 탐지·미일치와 조회 실패를 보여 줍니다.
- 문자 모드의 인증번호·송금 요구 문구는 URL 없는 정황만 평가합니다.
- 최근 1시간 기록만 요청하면 해당 기간의 근거를 사용하고 기록이 부족하면 제약 미충족을 설명합니다.
- 예방 계획은 종료 시각이 같은 날 시작 시각보다 늦아야 합니다. 기존 일정과 겹치면 저장 후 중복 ID를 알려 줍니다.

## 선택 및 검증 근거

urlscan.io는 공개 관측 후보, VirusTotal은 기존 엔진 보고서, Google Safe Browsing은 알려진 위협 목록에 사용합니다. 실제 API 응답 대조, 초기 Agent·Tool 변경, 대표 시나리오 검증과 19개별 구현·판정은 기존 검증표에서 확인합니다. [API 기획·실측](api-validation.md) · [필수 기능 검증표](final-validation.md) · [최신 분석 품질](analysis-quality-validation.md)
