# SCAMSHIELD AI 완성도 및 제출 준비 검토

2026-11-18 기준. 기능 코드는 수정하지 않았습니다. 기존 자동 테스트 88개를 다시 실행했습니다. Chrome 검토에는 임시 SQLite와 모의 보안 API를 사용했으며, 외부 API 정확도를 새로 실측하지 않았습니다. 제출물 목록은 [SSAFY 명세서](<../../AI코어프로젝트_3회차_요구사항정의서.pdf>) 28~30쪽을 기준으로 확인했습니다.

## 완성도와 장점

기능 시연이 가능한 MVP입니다. 최종 제출에는 입력·판정 표현의 보완과 제출용 증빙 정리가 필요합니다.

1. 결과에서 제공자별 상태, 관측 시각, 적용 조건, 제외 사유를 확인할 수 있습니다.
2. Planner·Worker·로깅 Agent가 검증한 실제 실행을 이벤트 순서대로 표시합니다.
3. 분석 이후 예방 행동과 일정 저장·충돌 확인까지 이어져, 사용자가 다음 행동을 관리할 수 있습니다.

## AI 분석 품질

- 모의 Google 위협 일치는 KNOWN_RISK, 두 공급자 오류는 INSUFFICIENT_EVIDENCE였습니다. 동일한 위협 일치에 최근 24시간 조건이 붙고 관측 시각이 없으면 SUSPICIOUS와 기간 조건 미충족으로 나타났습니다. 탐지 사실과 시각 제약을 결과에서 각각 보여 줄 여지가 있습니다.
- 목록 미일치는 NO_KNOWN_MATCH로 표시됩니다. 신규·단기 운영 피싱, 로그인 뒤 화면, 링크 없는 문자에는 외부 기록이 없을 수 있습니다. 단일 엔진과 Google의 상충 사례는 표현 강도의 위험을 확인한 것이며 실제 오탐율은 측정하지 않았습니다.
- 모델은 의도, 조회 선택, 제한된 응답 강조를 맡고 외부 결과와 위험 상태는 코드로 평가합니다. 모델이 조회 범위를 좁히거나 규칙이 문맥·부정 표현을 놓쳐 판단 근거가 줄어들 수 있습니다.
- 일부 공급자가 실패하면 확인 근거와 실패 코드가 함께 표시됩니다. 공식 채널에서 확인하고 인증정보 제공과 송금을 보류하는 안내는 유용하지만 누락된 검증에 맞춘 다음 행동이 더 명확해질 수 있습니다.
- 88개는 기능·회귀 검증 건수입니다. 실제 오탐·미탐·판정 보류를 평가하려면 공개 정상 URL, 공식 테스트 데이터, 출처가 확인된 피싱·사칭 예시, 링크 없는 문자, 출처 상충을 별도 층으로 둔 대표 사례가 필요합니다.

## UI/UX 점검

| 화면 | 관찰과 개선 방향 |
|---|---|
| 메인 | 브랜드와 분석 진입이 한 화면에서 드러납니다. URL 입력 예시와 문자 사례를 각각 한 건 제공하면 처음 쓰기 쉽습니다. |
| 입력 | URL·문자 탭과 개인정보 안내가 있습니다. 공개 URL에는 https:// 예시를 명확히 하고 문자 모드에서 원문만 처리하도록 개선이 필요합니다. |
| 분석 결과 | 색과 아이콘·문구로 상태를 구분합니다. 요약 직후에 가장 중요한 예방 행동과 출처 간 차이를 보여 주면 이해가 빨라집니다. |
| 출처별 근거 | 관측 시간, 제외 사유, 실제 조회 범위를 확인할 수 있습니다. 내부 코드·식별자와 세부 수치는 펼치기 영역에 적합합니다. |
| 타임라인 | Chrome 모의 실행 한 건에서 이벤트 39개를 확인했습니다. Planner·Worker 역할과 상세 이벤트가 표시됐습니다. 원본은 보존하고 오류·재계획 위주 요약으로 탐색을 줄일 수 있습니다. |
| 예방 계획 | 명시적 저장과 수정·삭제, 중복 일정 안내가 연결됩니다. 충돌 ID에 제목과 시간도 함께 제공하면 사용자가 대상을 알기 쉽습니다. |
| 실행 로그 | 목록에서 상세가 열립니다. F3020 판정·진단은 별도 API에 있으므로 원본 타임라인과 구분된 카드로 연결할 수 있습니다. |
| 모바일·데스크톱 | Chrome의 1440×960, 375×820, 320×740에서 가로 넘침은 없었습니다. 320×740에서 초기 분석 버튼 하단이 843px로 스크롤이 필요했습니다. 실제 기기 및 보조기기 종합 검증은 남아 있습니다. |

## F3022와 F3023

- F3022는 검증 가능한 공식 예방 절차와 대응 안내의 출처를 제시하는 데 가치가 있습니다. 프로젝트 코드·의존성·로컬 아티팩트와 Downloads의 관련 항목 이름에서 2회차 Vector DB나 적재 코드를 확인하지 못했습니다. 다른 위치의 보유 여부는 미확인입니다. 기존 DB와 출처·갱신 기준이 확인된 뒤 검토합니다.
- F3023은 실제 실행일이 있는 예방 계획에서 편리합니다. 입력·위험 판정 및 제출에는 직접 영향이 작고 계정 연결·동의·중복 등록 처리까지 필요합니다. 제출 전에는 보류가 적합합니다.
